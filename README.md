# TLH Service Maker for macOS

**[Download the newest version](https://github.com/W4KWK/TLHServiceMaker-releases/releases/latest/download/TLH-Service-Maker.dmg)**

1. Open the downloaded `TLH-Service-Maker.dmg`.
2. Drag **TLH Service Maker** into **Applications**.
3. Open it from Applications.

It needs macOS 13 or later on a Mac with Apple silicon (M1 or newer). The app is signed and notarized by Apple, so it
opens without warnings.

The link above always downloads the newest version. Earlier versions are listed under
[Releases](https://github.com/W4KWK/TLHServiceMaker-releases/releases).

Made for Christ the King Lutheran Church. This repository holds only the downloads.
