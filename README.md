# TLH Service Maker

Made for Christ the King Lutheran Church. This repository holds only the downloads.

## Mac

**[Download for Mac](https://github.com/W4KWK/TLHServiceMaker-releases/releases/latest/download/TLH-Service-Maker.dmg)**

1. Open the downloaded `TLH-Service-Maker.dmg`.
2. Drag **TLH Service Maker** into **Applications**.
3. Open it from Applications.

It needs macOS 13 or later on a Mac with Apple silicon (M1 or newer). The app is signed and notarized by Apple, so it
opens without warnings, and it updates itself: it offers each new version when one is ready.

## Windows

**[Download for Windows](https://github.com/W4KWK/TLHServiceMaker-releases/releases/download/windows/TLH-Service-Maker-Setup.exe)**

1. Open the downloaded `TLH-Service-Maker-Setup.exe` and follow the installer.
2. The installer is not signed, so Windows may say it protected your PC: choose **More info**, then **Run anyway**.

It needs Windows 10 or 11 (64-bit). It does not update itself: to update, download the installer again and run it over
the old one. Your services are kept.

## Linux

**[Download for Linux](https://github.com/W4KWK/TLHServiceMaker-releases/releases/download/linux/TLH-Service-Maker-x86_64.AppImage)**

1. Allow the downloaded `TLH-Service-Maker-x86_64.AppImage` to run as a program: in the file's Properties, or with
   `chmod +x TLH-Service-Maker-x86_64.AppImage`.
2. Open it. Nothing is installed.

It needs 64-bit Linux (x86_64): Ubuntu 22.04, Debian 12, Fedora 36, Linux Mint 21 or newer. If it does not open, run it
from a terminal with `--appimage-extract-and-run` at the end. It does not update itself: to update, download it again in
place of the old one. Your services are kept.
